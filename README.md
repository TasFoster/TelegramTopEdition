# 💬 TelegramTopEdition

*Десктопный клиент чата в стиле Telegram на Qt6 — учебный прототип интерфейса.*

## ✨ Возможности

Это прототип графического интерфейса мессенджера, собранный на Qt Widgets. Реализовано:

- **Список чатов** — слева три предзаданных чата, каждый открывается отдельной кнопкой (`ButtonChat`).
- **Переключение чатов** — клик по кнопке через сигнал `openChat(id)` загружает выбранную переписку в панель сообщений.
- **Отправка сообщений** — текст из поля ввода добавляется в историю чата по нажатию кнопки и сразу отображается списком.
- **Хранение переписки в памяти** — каждый чат держит свой список сообщений (`ChatData::ListSms`); при переключении показывается история именно этого чата.

> Это учебный прототип: сообщения хранятся только в оперативной памяти (без базы данных и без сети), набор чатов фиксирован в коде, оформление минимально.

## 🛠 Стек

- **C++17**
- **Qt 6** (модули `core`, `gui`, `widgets`)
- **qmake** — система сборки (`.pro`)
- UI-формы Qt Designer (`.ui`)

## 🚀 Сборка и запуск

```powershell
qmake ; mingw32-make
```

Или откройте `TelegramTopEdition.pro` в **Qt Creator** и запустите сборку (`Ctrl+R`).

## 📂 Структура

```
TelegramTopEdition/
├── TelegramTopEdition.pro   # проект qmake
├── main.cpp                 # точка входа, запуск MainWindow
├── mainwindow.{h,cpp,ui}    # главное окно, встраивает виджет чатов
├── chats.{h,cpp,ui}         # список чатов + панель открытого чата
├── chat.{h,cpp,ui}          # окно переписки: вывод сообщений и отправка
├── buttonchat.{h,cpp,ui}    # кнопка-элемент списка чатов (сигнал openChat)
└── chatdata.{h,cpp}         # модель данных чата (хранение сообщений)
```
